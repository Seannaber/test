How to Import in Workfront

  1. Log in to your Workfront instance as an administrator
  2. Navigate to Setup → System → Kick-Starts
  3. Click Import Data (Kick-Starts)
  4. Select your downloaded .xlsx file and click Upload
  5. Review the import results and resolve any errors

Note: ID reference fields (e.g., Project ID on Tasks) must contain valid Workfront object IDs from your instance.
